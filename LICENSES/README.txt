License texts and source locations

The portable publish script copies the license distributed with FFmpeg to this
folder. NuGet package license expressions and project URLs are recorded in
ThirdPartyNotices.txt and in the generated dependency manifests under obj.

FFmpeg LGPL information: https://ffmpeg.org/legal.html
NAudio: https://github.com/naudio/NAudio/blob/master/license.txt
CommunityToolkit: https://github.com/CommunityToolkit/dotnet/blob/main/License.md
Serilog: https://github.com/serilog/serilog/blob/dev/LICENSE
.NET runtime libraries: https://github.com/dotnet/runtime/blob/main/LICENSE.TXT
